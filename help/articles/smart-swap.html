Swap an exercise

Replace a movement while keeping the intended training target in view.

How to use it

  1. Open the exercise options in a plan or active session.
  2. Choose Smart Swap and review available alternatives.
  3. Select one that uses equipment you have and feels suitable; review the load before logging.

How to interpret it

Different exercises and machines have different mechanics. Compare performance within the same movement and setup where possible.
