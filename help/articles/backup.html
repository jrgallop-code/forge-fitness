Back up and restore your data

Keep a copy of local app data and avoid overwriting newer work.

How to use it

  1. Open More → Export & Backup to export a JSON backup.
  2. Keep the file in a place you control.
  3. To restore, choose Restore Backup and review the selected file.
  4. Signed-in cloud backup shows its state under More → Account & Cloud; resolve version conflicts before replacing data.
