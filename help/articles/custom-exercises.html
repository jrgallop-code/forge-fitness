Create a custom exercise

Add a movement that is missing from the exercise library.

How to use it

  1. Open the exercise picker and choose the custom exercise option.
  2. Name the movement and set its available properties.
  3. Add it to a plan or session and record sets as usual.

How to interpret it

Use a clear name so past entries remain easy to compare. A custom exercise does not automatically establish equivalent loads to another movement.
