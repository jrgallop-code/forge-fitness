Read Goal Progress

Compare your goal with the weight trend across the same selected window.

How to use it

  1. Open Progress → Weight.
  2. Swipe the chart carousel to Goal Progress.
  3. Use the date controls or pinch to adjust the visible range.
  4. Compare the trajectory with the goal marker, then review the actual measurements.

What the evidence means

A projected path is a planning aid; it cannot predict a precise future weigh-in.
