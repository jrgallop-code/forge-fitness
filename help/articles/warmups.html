Add warm-up sets and dynamic warm-ups

Prepare for a working set without counting warm-ups as working volume.

How to use it

  1. In the session, use the warm-up option for an exercise.
  2. Review suggested lighter sets and adjust the load to your equipment.
  3. If enabled, browse the dynamic warm-up movements before the session.
  4. Complete warm-ups, then log your working sets separately.

How to interpret it

Warm-ups are preparation, not a guarantee against injury. Build load gradually and use the range of motion that feels appropriate.
