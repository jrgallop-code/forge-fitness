Log a workout

Complete sets create the history used by progress charts and guidance.

How to use it

  1. Open Workout, choose a saved plan and start a day.
  2. Record weight and reps for each working set; add RPE when useful.
  3. Use the rest timer and edit sets as needed.
  4. Complete the session to save it to Workout History.
